## About

I am a Computer Engineering student at Tecnológico de Costa Rica (TEC) with a strong interest in cybersecurity. Through my Software Security coursework, I have explored complementary approaches to security analysis, including static software analysis, binary analysis through Capture the Flag (CTF) challenges, and architectural risk assessment.

I am particularly interested in understanding how software and systems can fail, investigating technical evidence, identifying security weaknesses, and communicating findings clearly. I have also participated in Hackatorio, a cybersecurity interest group at TEC.

This repository documents selected academic projects and the methods, tools, and findings described in their reports.

## Featured Projects

### 1. Identifying Software Weaknesses Through Static Analysis of `file`

**Area:** Static software analysis

An academic project focused on examining the `file` software through static analysis to identify software weaknesses.

The project report provides the detailed scope, methodology, observations, and supporting evidence.

### 2. Capture the Flag (CTF): Binary Analysis and Exploitation Techniques

**Area:** Binary analysis and penetration-testing challenges

An academic CTF project involving binary analysis, debugging, security tools, and Python-based scripting within the assigned challenge environment.

Tools used across the project include Ghidra, `file`, `checksec`, GDB, Netcat, Python 3, pwntools, Requests, threading, ROPgadget, `readelf`, and Detect It Easy (DIE).

- **Report:** [Read the project report (PDF)](./projects/02-ctf-binary-analysis/report.pdf)

### 3. Architecture Risk Analysis of a Conceptual System

**Area:** Security architecture and risk analysis

An academic assessment focused on analyzing the security risks of a conceptual system architecture. The report documents the scope, analysis, and conclusions of the exercise.

- **Report:** [Read the project report (PDF)](./projects/03-architecture-risk-analysis/report.pdf)
